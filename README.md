# Simulador de Investimentos em Fundos Imobiliários

Um simulador completo para análise e projeção de investimentos em Fundos de Investimento Imobiliário (FII).

## 📋 Sobre o Projeto

Este projeto oferece ferramentas para simular cenários de investimento em Fundos Imobiliários, permitindo análise detalhada de rentabilidade, riscos e projeções de retorno.

## 📊 Funcionalidades

- Simulação de cenários de investimento
- Cálculo de rentabilidade
- Análise de retorno sobre investimento (ROI)
- Projeções de fluxo de caixa
- Comparação entre diferentes fundos

## 🗂️ Arquivos

- `Simulador_Investimentos_Fundos_Imobiliarios_Excel_Resolvido.xlsx` - Planilha completa do simulador com exemplos resolvidos

## 🚀 Como Usar

1. Baixe o arquivo Excel `Simulador_Investimentos_Fundos_Imobiliarios_Excel_Resolvido.xlsx`
2. Abra em seu programa de planilhas (Excel, Google Sheets, LibreOffice, etc.)
3. Preencha os parâmetros de investimento
4. As projeções serão calculadas automaticamente

## 📝 Requisitos

- Microsoft Excel, Google Sheets, LibreOffice Calc ou similar
- Conhecimento básico sobre Fundos Imobiliários

## 💡 Dicas de Uso

- Modifique os valores de entrada conforme seus cenários
- As fórmulas estão pré-configuradas
- Mantenha o backup antes de fazer grandes alterações
